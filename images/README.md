# Images

Screenshots for the release page and the README. Owner is supplying these.

Wanted, roughly in the order they would be used:

1. Both pods on an A-19's pylons, ideally in the same shot so the size difference reads.
2. The artillery HUD mid-designation, with the footprint and reach arc visible.
3. A full salvo in flight.
4. Impact on a SHORAD site.
5. The pod close up, showing the hex flats and the skin.

Reference the finished ones from `README.md` and `GITHUB.md` as `images/<name>.jpg`.

`art/preview/` in this mod folder already holds eight renders of both pods from
`art/render_preview.py`. Those are lit previews rather than in-game shots, so they are
useful for the repo but not a substitute for 1 and 5.
